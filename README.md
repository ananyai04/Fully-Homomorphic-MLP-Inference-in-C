# Fully-Homomorphic-MLP-Inference-in-C
This project implements CKKS Homomorphic Encryption from scratch in zero-dependency C to perform secure Neural Network inference on the Iris dataset, keeping data fully encrypted throughout the pipeline. It features a high-performance Residue Number System (RNS) backend with 128-bit integer extensions and a custom Negacyclic NTT engine, reducing arithmetic complexity from O(N²) to O(N log N) in the Z[x]/(x⁸¹⁹² + 1) ring. A hybrid-homomorphic MLP pipeline (4→8→3) uses partial decryption for x² activations while executing Layer-2 fully homomorphically. Core cryptographic primitives include a Box-Muller Gaussian sampler and recursive FFT encoders, with careful fixed-point rescaling to control the multiplicative noise budget — demonstrating a complete, precise, encrypted inference flow.
