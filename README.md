# Fully-Homomorphic-MLP-Inference-in-C
Zero-dependency C implementation of CKKS Homomorphic Encryption for secure NN inference on Iris dataset. Features a custom RNS backend, Negacyclic NTT engine (O(N log N)), and a hybrid-homomorphic MLP (4→8→3) pipeline with partial decryption — achieving precise, fully encrypted end-to-end classification.
